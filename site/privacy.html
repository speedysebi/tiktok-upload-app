Privacy Policy

Last updated: November 24, 2026

1. Who this covers

Clip Relay is a private desktop tool. One person, the account owner, uses it with their own TikTok accounts and nobody else's. It has no users besides the owner, no website accounts and no sign-up.

2. What data Clip Relay gets from TikTok

When the owner connects a TikTok account, TikTok gives Clip Relay:

  • an access token and a refresh token, which let Clip Relay upload drafts to that account;
  • the account's TikTok user ID (open_id), the granted permissions (scopes) and the tokens' expiry times.

Clip Relay asks for only two permissions: user.info.basic, used only to check that the connection still works, and video.upload, used to send drafts to the account's TikTok inbox. It does not read the account's videos, followers, messages, comments or analytics.

3. Where it is stored

The tokens and the data listed above are stored only on the owner's own computer, in a file only the owner's user account can read. Clip Relay has no server and no database in the cloud, and keeps no copy anywhere else.

The video files it uploads are the owner's own edited clips. They go straight from the owner's computer to TikTok.

4. What Clip Relay does not do

  • It does not sell, rent or share any data with anyone.
  • It does not use data for advertising, profiling or tracking.
  • It does not collect data about other TikTok users or viewers.
  • It uses no analytics, cookies or third-party trackers, and neither does this website.

5. How long data is kept

Tokens are kept until the owner disconnects the account. TikTok's refresh token expires after a while on its own, at which point the owner has to reconnect. To delete everything, the owner deletes the token file on their computer and/or removes Clip Relay's access in the TikTok app's settings. After that, Clip Relay can no longer access the account.

6. TikTok's own handling

Content uploaded through Clip Relay, once published, is handled by TikTok under TikTok's own Privacy Policy.

7. Changes

This policy may change. The current version is always on this page, with its "last updated" date.
